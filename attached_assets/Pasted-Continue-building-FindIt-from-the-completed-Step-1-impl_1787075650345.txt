Build the **visual annotation and image-processing foundation** for FindIt.

Do NOT implement YOLO training, embeddings, personalized model training, or natural-language search yet.

**Phone Camera → Capture Image → Select Object → Annotate Bounding Box → Save Annotation**

This will prepare the data pipeline that we will use for YOLO in Step 3.

# 4. Bounding Box Annotation Tool

This is the most important feature of Step 2.

Create a mobile-friendly image annotation interface.

Example:

```text
┌───────────────────────────┐
│                           │
│       PHONE IMAGE         │
│                           │
│      ┌────────────┐       │
│      │ HEADPHONES │       │
│      └────────────┘       │
│                           │
└───────────────────────────┘

[Clear]             [Confirm]
```

The user should be able to draw a rectangular bounding box using their finger.

Requirements:

* Touch interaction
* Drag from one point to another
* Correctly handle dragging in any direction
* Prevent coordinates from going outside the image
* Correctly map screen coordinates to original image coordinates
* Work with portrait and landscape photos
* Handle different aspect ratios
* Display the selected object's name above/beside the bounding box
* Allow the user to clear and redraw the box
* Allow the user to confirm the annotation

Do NOT use mouse-only interactions.

The annotation tool must work on an actual smartphone touchscreen.

---

# 5. Coordinate System

Store bounding-box coordinates relative to the original image rather than the displayed canvas.

Use normalized coordinates where possible:

```text
x
y
width
height
```

normalized between:

```text
0.0 → 1.0
```

Also retain the original image dimensions.

For example:

```text
{
  "x": 0.32,
  "y": 0.41,
  "width": 0.28,
  "height": 0.19,
  "imageWidth": 1920,
  "imageHeight": 1080
}
```

This will make the annotations independent of the phone screen size.
